# Digital-Stopwatch-with-Lap-Timer

## Project Description

The Digital Stopwatch is a simple, interactive, and responsive web application developed using **HTML, CSS, and JavaScript**. It allows users to measure elapsed time accurately with Start, Stop, Reset, and Lap functions. The application has a clean, user-friendly interface and works on both desktop and mobile devices.

## How It Works

1. **Start:** Click the Start button to begin counting time in hours, minutes, and seconds.
2. **Stop:** Click the Stop button to pause the stopwatch without losing the recorded time.
3. **Reset:** Click the Reset button to set the timer to 00:00:00 and clear all recorded laps.
4. **Lap:** Click the Lap button to record the currently displayed time in a list without stopping the stopwatch.
5. **Keyboard Shortcuts:** Press S to start, E to stop, R to reset, and L to record a lap.

## Technologies Used

- **HTML:** Creates the stopwatch structure, buttons, and time display.
- **CSS:** Provides the modern design, layout, colours, and responsive interface.
- **JavaScript:** Controls the timer, button functions, lap recording, and keyboard shortcuts.

## Conclusion

This project demonstrates how HTML, CSS, and JavaScript work together to create a functional stopwatch. It provides a simple and effective way to track time and record laps through an easy-to-use interface.
